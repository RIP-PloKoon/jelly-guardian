# Legacy Helper Tools

This folder contains inherited helper scripts and console utilities from the original project.

They are kept for developer reference, but they are not the maintained installation or verification path for this fork.

Current primary user workflow:

1. Add the Jellyfin custom repository URL.
2. Install the plugin from Jellyfin's plugin catalog.
3. Run Subtitle Extract or provide external text subtitles.
4. Run the Profanity Filter scheduled scan.
5. Verify playback in Jellyfin web.

Repository URL:

```text
https://raw.githubusercontent.com/RIP-PloKoon/jellyfin-profanity-filter-repo/main/manifest.json
```

Legacy files in this folder may still mention older manual DLL installs, sidecar `.profanity.json` files, or local test simulations. Update them before using them as supported documentation or automation.
